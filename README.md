# StuFolio

**Build Your Portfolio in Minutes.**

StuFolio is a simple portfolio builder made for students. It helps students create and share their own portfolios without building a website from scratch.

## Features

* Create a student portfolio
* Choose from available templates
* Add personal information
* Preview your portfolio
* Share your portfolio
* User authentication
* Store portfolio data with Supabase

## Built With

* HTML
* CSS
* JavaScript
* Tailwind CSS
* Supabase
* PostgreSQL
* Vite
* Vercel

## How It Works

1. Create an account
2. Create a new portfolio
3. Choose a template
4. Add your information
5. Preview your portfolio
6. Share your portfolio

## What I Learned

I started StuFolio with basic HTML, Tailwind CSS, and JavaScript knowledge. While building it, I learned Supabase, async/await, authentication, database operations, and how to build and deploy a real web project.
